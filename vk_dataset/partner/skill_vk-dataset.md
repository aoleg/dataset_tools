## Как вызывать

- Рабочая папка — `vk_dataset` (проект OpenCode). Каждая команда: `..\venv\Scripts\python.exe vkds.py <глагол> ...`.
- НЕ вызывай `run.bat`: при ошибке он ждёт нажатия клавиши, и ты повиснешь. `run.bat` — для человека.
- Пути и токен берутся из `vkds.conf` (рядом с `vkds.py`): `base` — корень датасетов, `--out <тема>` — папка внутри `base`. Токен читается из `vk_token.txt` сам. НИКОГДА не выводи токен, не читай файл токена, не вставляй токен в команды.
- `--help` у каждого глагола — по-русски: `..\venv\Scripts\python.exe vkds.py <глагол> --help`.

## Глаголы и цена в вызовах API

Файлы с CDN бесплатны; платят только списки.

| Глагол | Что делает | Вызовов |
| --- | --- | --- |
| `search groups --q "<запрос>" [--q ...] --out <тема>` | поиск групп по названию и описанию → `_candidates.json` и короткая таблица | 1 на запрос + 1 на 500 найденных групп |
| `sample <группа> --sheet --out <тема> [--from albums]` | 12 фото группы и лист `sheet.jpg` в `_samples\<папка группы>\` | 1 со стены, 2 из альбома, +1 для группы не из `_candidates.json` |
| `scan albums <группа> --out <тема>` | альбомы группы с размерами → `_albums.json` | 1 + 1 на 100 альбомов |
| `scan wall <группа> --out <тема> [--since ГГГГ-ММ-ДД]` | индекс стены → `_wall.json`, сводка по годам и смета | 1 + 1 на 100 постов |
| `albums <группа> --min-side 512 --out <тема>` | скачивание альбомов; альбом, где ничего не недостаёт, бесплатен | 1 + 1 на 100 альбомов + 1 на 1000 фото листаемого альбома |
| `wall <группа> --min-side 512 --out <тема>` | фото отобранных постов (`--since`, `--until`, `--text-regex`, `--photos-min`, `--post-id`) | 1 на 100 постов, где не хватает фото |
| `peek <группа> --album-id ID --limit 6 [--offset N] --out <тема>` | пробы альбома в `_peek\` для осмотра | 2 |
| `whoami --group <группа>` | проверка токена | 1 |
| `budget [--out <тема>]` | журнал этой копии за месяц и журнал датасета | 0 |
| `recheck-dead <группа> [--sizes] [--limit N] --out <тема>` | перепроверка мёртвых фото по реестру | 0 |
| `migrate <тема> [--dry-run]` | переименование датасета до версии 0.5 | 0 |

- `<группа>` — короткое имя, id или ссылка.
- Поиск групп и отбор фото по условию — по шагам скилла `vk-agent-scenarios`.
- `wall` требует предварительного `scan wall`. `wall --dry-run` не тратит ни одного вызова и не требует токена.
- Повторный `scan wall` дешёв: останавливается на уже известном посте.
- `--redownload-missing` — только если владелец прямо просит вернуть файлы, убранные из датасета.

## Разведка прежде скачивания (железное правило, AGENTS.md §6)

1. `scan albums` и `scan wall` по каждой группе-кандидату; прочитай сводку, не файлы целиком.
2. Сомнительные альбомы — `peek` с начала и из середины (`--offset`).
3. План и смета: `albums ... --dry-run` и `wall ... --dry-run`.
4. Покажи план и смету владельцу и жди «да» — вопрос через инструмент `question`, как велит AGENTS.md §10 (варианты «Да» / «Нет» / «Покажи подробнее»).
5. Скачивание — только после «да» и с `--budget N` (смета плюс 20 %).
6. Контрольный повторный прогон той же команды — он почти бесплатен и докачает пропущенное.
7. После серии команд — `budget`, цифры месяца в STATUS.md.

## Шаги 1–4 цепочки (твоя машина)

1. `scan albums` и `scan wall` (см. выше).
2. `albums <группа> --min-side 512 --out <тема>` и `wall <группа> --min-side 512 --out <тема>`. Порог 512 по стороне — порог нашего импорта; мельче нет смысла качать.
3. Дубли: `..\venv\Scripts\python.exe ..\deduplicate\dedup.py <папка группы> --gpu` — сначала с `--dry-run`. Подробно — скилл `dataset-tools-postprocess`.
4. Фото не по теме: `..\venv\Scripts\python.exe ..\scripts\unrelated.py <папка группы> --endpoint http://127.0.0.1:11434/v1/` — сначала с `--dry-run`.

«Папка группы» — полный путь `<base>\<тема>\<папка группы>`; имя папки группы печатает `scan` («Папка группы: «...»»), это название группы, а не короткое имя. Шаги 5–7 (импорт, пересортировка, подписи моделью) выполняются у архитектора: после шага 4 владелец отправляет папку группы вручную.

## Коды выхода

- `0` — готово.
- `1` — ошибка (VK API кроме лимита, сбой) — доложи текст ошибки.
- `2` — отказ: нет токена, нет `base`/`--out`, нет индекса стены, достигнут `--budget`, или ошибка лимита ВК. При ошибке лимита НЕ повторяй команду: отметка записана в журнал, жди сброса и доложи владельцу.
- `130` — прервано; та же команда докачает.

## Чего не делать

- Не качать без разведки, сметы и «да» владельца.
- Не повторять команду при ошибке лимита.
- Не читать в контекст большие файлы (`_wall.json`, `_manifest.csv`, папки с фото): только сводки команд и короткие выборки скриптом.
- Не трогать файлы в `vkds\`, `tools\` и других папках dataset_tools; черновики — в `tmp\agent_drafts\`.
