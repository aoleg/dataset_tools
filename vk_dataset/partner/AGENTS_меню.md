# Правки в AGENTS.md: меню инструментов и скиллы инструментов

Это список правок для владельца (или для агента под присмотром владельца) в файле `AGENTS.md` папки проекта. Что это даёт и как настроить права в `opencode.jsonc`, написано в `МЕНЮ.md`; текст нового скилла — в `skill_dataset-tools-menu.md`. Заглушки те же, что в `ПЕРЕХОД.md`.

Главное правило: AGENTS.md загружается целиком в начале каждой сессии и занимает часть окна в 64K. Поэтому в него попадают только короткие правила ниже, а меню, таблица инструментов и порядок построения скиллов живут в скилле `dataset-tools-menu`, который загружается по требованию.

## Раздел 13 для вставки

    ## 13. Меню инструментов и скиллы инструментов

    В начале сессии, после STATUS.md, загрузи скилл `dataset-tools-menu` и спроси
    владельца инструментом question: «С чем работаем сегодня?» — группа работы,
    затем инструмент. Если владелец в первом сообщении уже поставил задачу или
    назвал инструмент, меню пропусти.

    Для выбранного инструмента есть свой скилл `tool-<имя>` (имя папки
    инструмента, `_` заменено на `-`). Есть в списке скиллов — загрузи и работай
    по нему. Нет — построй его сам по порядку из `dataset-tools-menu`: источники
    только `--help` инструмента и его README, файл `.opencode\skills\tool-<имя>\
    SKILL.md`, по-русски, не длиннее 60 строк, ни одного флага, которого нет в
    `--help`. Скажи владельцу одной строкой, что скилл создан, и продолжай
    задачу. Если команда из скилла даёт «unrecognized arguments» — инструмент
    обновился, перестрой скилл.

    Для любого инструмента: сухой прогон, разбор отчёта, вопрос владельцу,
    боевой прогон. Файлы dataset_tools только читать и запускать. Не в меню:
    pastvu, classify, pipeline.
